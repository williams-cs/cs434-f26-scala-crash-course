# Scala Crash Course

A lab introducing sbt and the Scala you need for this course.
Follow the "Scala Crash Course" handout on the course web page.

# To Compile:

    sbt compile

# To Run:

    sbt run

# To Test:

    sbt test

`Main.scala` is a guided tour: read it top to bottom and check what it
prints.  `Exercises.scala` contains small functions to write; make the
tests in `ExercisesTests.scala` pass one at a time (only the first
test passes with the starter).
